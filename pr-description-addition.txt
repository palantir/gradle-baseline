# Test Migration Errors and Fixes

## Initial Migration Issues

### Error 1: Plugin declarations in append() block
**Error**: Compilation failed with error-prone check `[GradleTestPluginsBlock]`
```
error: [GradleTestPluginsBlock] Plugins must be added using .plugins().add() method.
```

**Solution**: Changed from using `apply plugin: 'plugin-name'` inside the `append()` block to using the fluent API:
```java
rootProject.buildGradle()
    .plugins()
    .add("plugin-name");
```

**Reference**: Error-prone checker enforces this pattern to ensure proper plugin block handling in the testing framework.

## Review Pass - Best Practices Check

### Error 2: Using .formatted() instead of varargs overload
**Error**: Compilation failed with error-prone check `[GradleTestStringFormatting]`
```
error: [GradleTestStringFormatting] Use the varargs overload of methods to get syntax highlighting, rather than manually formatting strings with .formatted() or String.format()
```

**Solution**: Changed from using `.formatted()` to passing the arguments directly as varargs:
```java
// Before
rootProject.buildGradle().append("""
    dependencies {
        annotationProcessor '%s'
    }
    """.formatted(IMMUTABLES));

// After
rootProject.buildGradle().append("""
    dependencies {
        annotationProcessor '%s'
    }
    """, IMMUTABLES);
```

**Reference**: The testing framework's `append()` method has a varargs signature `append(String template, Object... args)` that provides syntax highlighting benefits.

**Change**: Added blank lines after text blocks for improved readability, as recommended in the migration guide.
